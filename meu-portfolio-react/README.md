# Meu Portfólio React

Este é o meu portfólio pessoal, reconstruído usando React, Tailwind CSS e Sass para uma experiência moderna e responsiva.

## Tecnologias Utilizadas

- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **Tailwind CSS**: Framework CSS utilitário para estilização rápida e responsiva.
- **Sass**: Pré-processador CSS para estilos avançados.
- **Vite**: Ferramenta de build rápida para desenvolvimento.

## Funcionalidades

- **Sobre Mim**: Uma seção introdutória sobre minhas habilidades e experiência.
- **Habilidades**: Barra de progresso mostrando minhas competências técnicas.
- **Projetos**: Galeria de projetos destacados com descrições e tecnologias usadas.
- **Contato**: Formulário para entrar em contato.
- **Controle de Gastos**: Ferramenta interativa para gerenciar despesas pessoais.

## Como Executar

1. Navegue até a pasta do projeto:
   ```
   cd meu-portfolio-react
   ```

2. Instale as dependências:
   ```
   npm install
   ```

3. Execute o servidor de desenvolvimento:
   ```
   npm run dev
   ```

4. Abra o navegador e acesse `http://localhost:5173`.
